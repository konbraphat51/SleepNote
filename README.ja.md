# SleepNote

SleepNote はブラウザで使える睡眠日誌です。1か月が1ページ、1日が1行で、30分ごとの48スロット（00:00〜24:00）があります。各スロットを3つの状態で塗り分け、特定のスロットにアイコンを配置し、その月をPDFとして保存できます。

- **1か月1ページ**、1日1行、48スロット × 30分
- **3つの状態**はモノクロ印刷でも区別可能: 睡眠（塗りつぶし）、在床覚醒（斜線ハッチ）、活動中眠気（ドット）
- スロットに**2種類のアイコン**: 服薬（カプセル）と食事（フォーク＆ナイフ）
- **Cookie保存**と、JSON書き出し・読み込みによるバックアップ
- **元に戻す / やり直す** — 編集の取り消し・再適用（ツールバーのボタンと Ctrl+Z / Ctrl+Shift+Z）
- ブラウザの印刷ダイアログによる**月ごとのPDF**（A4横向き）
- ホバーでスロットの**日付・時刻ツールチップ**を表示
- **ホバーのクロスヘア** — カーソル上のスロットの行と列を薄くハイライト
- **ドラッグで連続塗り** — ドラッグは開始した日（行）の中だけを塗るため、誤って他の日へドラッグしても塗られません
- **右クリックで消去** — 塗ったスロットを右クリックすると塗りを消去します（消しゴムツールと同じ）
- **日ごとの備考** — 各日の行の右端に1行のメモ欄
- **英語UIが既定**で、日本語への切り替えに対応

## セットアップ

リポジトリをクローンし、pnpm で依存関係をインストールします。

```sh
git clone https://github.com/konbraphat51/SleepNote.git
cd SleepNote
pnpm install
pnpm dev
```

Vite が表示する URL（既定では http://localhost:5173）を開きます。

## 2回目以降の起動

次のコマンドで開発サーバーを再起動します。

```sh
pnpm dev
```

## 主なCLI

| コマンド        | 用途                             |
| --------------- | -------------------------------- |
| `pnpm install`  | 依存関係をインストール           |
| `pnpm dev`      | Vite開発サーバーを起動           |
| `pnpm build`    | `dist/` に本番ビルド             |
| `pnpm preview`  | 本番ビルドをローカルで確認       |

## データ保存

日誌データはすべて1つのブラウザCookie（`sleepnote_diary`）に保存されます。ブラウザのCookieは1つあたり約4KBまでという制限があるため、1スロット1文字のコンパクトな形式を採用していますが、長期間の記録では上限に達することがあります。ツールバーの**「JSONを書き出す」**で完全なバックアップをダウンロードし、**「JSONを読み込む」**で復元してください。UIの言語設定は別の `sleepnote_language` Cookieに保存されます。

## PDF書き出し

ツールバーの**「PDF / 印刷」**をクリックするとブラウザの印刷ダイアログが開くので、**「PDFに保存」**を選択します。印刷用スタイルはA4横向きで、現在表示中の月のグリッドだけを印刷します（ツールバー・凡例・警告は非表示）。3種類の塗り分け（塗りつぶし・斜線ハッチ・ドット）は、モノクロ印刷でも区別できるデザインです。

## GitHub Pages へのデプロイ

このアプリは GitHub Actions で `https://konbraphat51.github.io/SleepNote/` にデプロイされます。

1. `main` ブランチにプッシュします（またはワークフローを手動実行します）。
2. `.github/workflows/deploy.yml` が `pnpm install` と `pnpm build` を実行し、`dist/` を GitHub Pages にデプロイします。
3. 初回のみ: **Settings → Pages → Build and deployment → Source** を開き、**GitHub Actions** を選択します。
